How these numbers are estimated
  • Weights = parameters × bits per number ÷ 8. For a mixture-of-experts model, every expert must be stored, so the total size counts, not the active size.
  • Runtime overhead is assumed to be 20% on top of the weights.
  • The KV cache (the model’s working notes) is a rough estimate that grows with context length.
  • Apple Silicon: about 75% of unified memory is usable by the GPU. CPU only: your free RAM minus 4 GB.
  • INT4 and INT2 use the nominal bit count. Real 4-bit files (such as Q4_K_M) average about 4.5–5 bits, so expect roughly 10–25% more.
  • Sizes use GB = 10⁹ bytes. Your system may report GiB (2³⁰ bytes), which is about 7% smaller.
